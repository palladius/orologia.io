# Orologia.io (Codenamed: Time Master)

![Orologia.io Logo](logo.jpg)


A mobile clock-learning game designed to teach children (Sebi and Alessandro) how to read analog clocks, update digital displays, and understand Binary Coded Decimal (BCD) configurations.
